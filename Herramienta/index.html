¿Qué es Apache Hive?

Data warehouse open-source construido sobre Hadoop.

↓ Descripción · Características · Funcionamiento

¿Qué es?

Apache Hive es una herramienta de Big Data construida sobre Hadoop que permite consultar y gestionar grandes volúmenes de datos distribuidos utilizando HiveQL, un lenguaje prácticamente idéntico al SQL tradicional. Su gran ventaja es que traduce consultas sencillas de bases de datos en procesos complejos de Apache Hadoop, facilitando el análisis masivo sin necesidad de programar en código complejo.

Características

✅ Data warehouse open-source construido sobre Hadoop.
✅ Le pone una interfaz SQL (HiveQL) a datos enormes guardados como archivos.
✅ Traduce tu SQL a trabajos distribuidos (Tez / MapReduce / Spark).
⚙️

¿Para qué sirve? / Uso

Análisis masivo de datos mediante SQL.

↓ Descripción · Usos principales · Formatos soportados

Uso

Se utiliza principalmente para el análisis de datos históricos acumulados (Business Intelligence), la minería de datos y la ejecución de procesos ETL (extraer, transformar y cargar información a gran escala). Es ideal para procesar cargas masivas de trabajo por lotes, aunque no está diseñado para consultas en tiempo real o transacciones rápidas.

¿Para qué sirve?

📊 Analítica por lotes (OLAP)
Analizar datasets gigantes (TB–PB) con SQL, sin programar Java.
🔄 Procesos ETL
Extraer, transformar y cargar información a gran escala.
📁 Catálogo central de tablas
Soporta CSV, JSON, Parquet, ORC e Iceberg.

Descripción del Diagrama

El diagrama que realizamos muestra el flujo de la arquitectura de Hive, donde la interfaz recibe la consulta del usuario, el Driver la compila y optimiza, y el Metastore (que guarda el diccionario de tablas y columnas) ayuda a ubicar los datos para que el motor de ejecución procese la orden final dentro del sistema de almacenamiento distribuido.

Creadores y Soporte

Historia y respaldo del proyecto.

↓ Origen · Comunidad · Soporte comercial · Versión actual

Origen

🏗️ Creado en Facebook por Joydeep Sen Sarma y Ashish Thusoo (~2007–2008). Fuente: Databricks
🎤 Presentado en el Hadoop Summit 2008; luego donado a Apache. Fuente: YourStory

Comunidad y Soporte

🌐 Hoy es un proyecto top-level de la Apache Software Foundation (comunidad open-source). Fuente: Databricks
🛠️ Soporte comercial/gestionado: AWS EMR, Cloudera, Google Dataproc, Azure HDInsight.
🔢 Versión actual 4.x (la línea 3.x ya es End of Life).
